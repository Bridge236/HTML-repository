第一章 选基方法论：四步漏斗法

选基金不是看排行榜抄作业，而是通过四层筛选逐步缩小范围，最终留下经得起考验的优质基金。以下是完整流程：

第一步：定底线 — 筛掉风险不匹配的（淘汰约60%）
只保留 R2纯债 + R3偏债混合/二级债基，排除所有 R4及以上
▼
第二步：看长期 — 筛掉短跑冠军（再淘汰约50%）
只看近3年收益，纯债<8%、偏债混合<20% 的直接淘汰
▼
第三步：查背景 — 筛掉小作坊（再淘汰约30%）
规模<10亿、经理任职<2年、机构占比>80% 的不要
▼
第四步：分散配 — 筛掉同质化的（最终留5只）
利率债、信用债、二级债基各选代表，同经理只选1只

第四步：从筛选结果中精选

筛选结果可能仍有十几只基金，需要进一步人工甄别。打开每只基金的详情页，检查以下清单：

  • 基金经理稳定性：详情页 → 基金经理 → 任职日期是否 ≥ 2年。频繁换人的不要
  • 持仓集中度：详情页 → 基金持仓 → 前五大重仓债券占比是否 < 30%。过于集中的不要
  • 机构持有比例：详情页 → 规模份额 → 机构持有比是否 < 80%。过高的流动性差
  • 分红记录：详情页 → 分红送配 → 是否有持续分红。定期分红说明运作成熟
  • 费率水平：详情页 → 费率 → 申购费是否 ≤ 0.15%（打折后）。管理费纯债 ≤ 0.6%/年
  • 回撤对比：详情页 → 业绩走势 → 最大回撤是否优于同类平均

扣款日选择技巧
  • 避开月初1-5日：很多工资发放日在5-10日，银行卡余额可能不足
  • 避开月末25-31日：信用卡还款日集中，资金紧张
  • 推荐选择发薪日后2-3天：确保卡里有足够余额
  • 多只定投错开日期：如本方案8/10/12/15/18日，避免同一天扣款压力
  • 注意节假日顺延：如果扣款日是周末或节假日，银行会顺延到下一个工作日扣款
定投金额调整规则
场景 操作 说明
市场大涨（债市涨幅>1%） 维持不变 不要因为涨了就加码，定投的核心是纪律性
市场大跌（债市跌幅>1%） 可手动加投1次 大跌时加投是"捡便宜"，但不要把定投金额改高

第八章 常见问题

Q1：定投扣款日当天余额不足怎么办？

银行会在扣款日当天尝试扣款1次。如果失败，当月不会补扣。建议在扣款日前1天确保卡内余额充足。如果当月漏扣，可以手动买入等额份额补上。

Q2：纯债基金也会亏钱吗？

会，但概率低、幅度小。纯债基金短期亏损通常因市场利率上行导致债券价格下跌，但持有6个月以上基本都能回正。因为债券有票息收益（持有到期还本付息），时间越长正收益概率越高。

Q3：003877富国久利近1年收益从24%降到13%，是不是不行了？

这是正常回调。偏债混合基金有少量权益仓位，会随股市波动。近3年+59.15%说明长期赚钱能力没问题，短期回调反而是定投的好时机——同样的钱能买到更多份额。

Q4：能不能用余额宝/货币基金替代纯债定投？

不建议。货币基金当前年化约1.2-1.5%，接近银行定存。纯债基金虽然短期有波动，但近3年收益9-16%，长期跑赢货币基金3-5个百分点。定投正好熨平短期波动。

Q5：如果急需用钱怎么赎回？

APP → 我的 → 持仓 → 选择基金 → 赎回。债券基金赎回T+1到账（T日15:00前提交）。建议优先赎回盈利最多的那只，保留亏损的继续定投摊低成本。持有不满7天有1.5%惩罚性赎回费，注意避开。

Q6：5只基金会不会太多了管不过来？

不会。定投设置好之后是自动扣款的，日常不需要操作。每季度花10分钟检查一次即可。5只基金的分散度恰好——少了不够分散，多了收益被稀释。如果实在觉得多，可以先从003376+003547两只纯债开始。
