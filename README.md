# 塔罗牌占卜网站

一个纯静态的塔罗牌在线占卜网站，支持单牌占卜和牌阵占卜。

## 功能

- **单牌占卜**：随机抽取一张塔罗牌，获得AI解读
- **牌阵占卜**：选择不同牌阵（三牌、凯尔特十字等），多维度解读
- **塔罗学习**：78张塔罗牌完整图鉴与牌义学习
- **百科查询**：按关键词快速检索塔罗知识

## 技术栈

纯静态 HTML + CSS + JavaScript，无需后端服务。
